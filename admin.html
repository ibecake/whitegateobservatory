Settings

Tokens are stored in sessionStorage for this tab and are never written to the repo. Uploads also need a CORS policy on the bucket that allows this site origin.

How to get tokens and enable CORS

Print a short-lived GCS token:

gcloud auth print-access-token

Apply CORS so the browser can upload from this page (adjust the origin if needed). An example file is assets/data/gcs-cors.example.json:

[
  {
    "origin": ["https://whitegateobservatory.com", "http://localhost:8000"],
    "method": ["GET", "HEAD", "PUT", "POST", "OPTIONS"],
    "responseHeader": ["Content-Type", "Authorization", "x-goog-resumable"],
    "maxAgeSeconds": 3600
  }
]

gcloud storage buckets update gs://whitegate-astrophotography --cors-file=cors.json

Without tokens you can still edit the manifest, download it, and copy gcloud storage cp commands.

Bucket not listing?

Anonymous listing needs public object viewer on the bucket, or a GCS token in Settings.

gcloud storage buckets add-iam-policy-binding gs://BUCKET_NAME \
  --member=allUsers --role=roles/storage.objectViewer
