Media Admin

The gallery pages only show files listed here. Files can already be in the Google Cloud bucket — you still need to Add them, then Save to the website.

Add a file that is already in the bucket

  1. Choose the section below (Astrophotography, Radio Astronomy, or Radio).
  2. Wait for the bucket list. Click Add to page on each file you want. Use JPEG/PNG/WebP — HEIC will not show in a browser.
  3. Check the new card: title, date, tags.
  4. Click Save to the website (top right). The list is copied and GitHub opens. Paste over the file, commit to main, wait a minute, then hard-refresh the gallery.

What “Save to the website” does
  1. Copies the updated gallery list to your clipboard.
  2. Opens the GitHub file editor for this section’s manifest.json.
  3. In that tab: select all, paste, click Commit changes (leave it on the main branch).
  4. Wait for Pages to rebuild, then hard-refresh the gallery (Ctrl+Shift+R).

If you paste a GitHub token with repo scope in Settings, Save will commit for you instead of opening the editor.
