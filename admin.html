Media Admin

This page loads the latest gallery list from GitHub. Add or remove files here, keep tags and targets, then Save to the website. A file in the Cloud bucket is not on the public gallery until it appears in this list and you save.

How publishing works

  1. This page opens on the files already listed on the live gallery (from GitHub main).
  2. Bucket files that are not listed yet show Add to page. Cards already on the gallery can be removed.
  3. Tags and targets stay in the library even if no photo currently uses them, until you delete them here.
  4. Putting a file in the bucket only stores the binary. Listing it on the gallery needs Save to the website.
  5. After a successful save you will see a confirmation with the item count. Wait about a minute, then hard-refresh the gallery.

4. Save to the website

This updates astrophoto/manifest.json in GitHub. Save merges with the latest GitHub list so existing gallery items are not wiped unless you removed them here. After commit, GitHub Pages republishes in about a minute.

What “Save to the website” does
  1. Fetches the latest GitHub list and merges it with this page (your adds, edits, and removals win).
  2. If a GitHub token with repo scope is in Settings, Save commits for you and shows a confirmation.
  3. Otherwise it copies the merged JSON and opens the GitHub editor: select all, paste, commit on main.
  4. Wait for Pages to rebuild, then hard-refresh the gallery (Ctrl+Shift+R).
