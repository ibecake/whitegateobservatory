Bucket not listing? (make it public / list-enabled)

The builder lists objects with the public Cloud Storage JSON API, which needs anonymous read on the bucket. Grant it once:

gcloud storage buckets add-iam-policy-binding gs://BUCKET_NAME \
  --member=allUsers --role=roles/storage.objectViewer

You can still add files manually by object name without listing.
